The base surface of GorditOS — a rounded paper card resting on cream.

```jsx
<Card variant="tint">
  <h3>Tu jardín</h3>
  <p>12 días activos este mes 🌱</p>
</Card>
<Card interactive>…tappable…</Card>
```

Variants: `default` (soft shadow), `raised` (more elevation), `flat` (hairline border, no shadow), `tint` (soft green panel for info). Add `interactive` for tappable cards.
