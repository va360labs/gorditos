The "jardín de hábitos" — a calendar grid where active days grow plants. The non-negotiable rule: an empty/missed day is `soil` (tierra), never a wilted or dead plant. There is no decay state.

```jsx
<GardenGrid columns={7} days={[
  'grown','bloom','sprout','soil','grown','grown','bloom',
  'soil','sprout','grown', /* … */
]} />
```

Pair with constancy copy like "12 días activos este mes" / "tu mejor mes" — never streaks that break.
