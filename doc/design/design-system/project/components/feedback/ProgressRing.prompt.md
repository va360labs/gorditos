Circular progress for adaptive goals (steps from real average +500, water). The goal is never the 10.000 dogma, and falling short shows no negative messaging.

```jsx
<ProgressRing value={4300} max={5200} label="4.300" sub="pasos hoy" />
<ProgressRing value={6} max={8} label="6" sub="vasos" color="var(--sky-500)" size={96} />
```
