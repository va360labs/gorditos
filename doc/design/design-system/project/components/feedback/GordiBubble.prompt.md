Speech bubble for the Gordi copilot (motivation chat, daily tip, kind comeback messages).

```jsx
<GordiBubble from="gordi" avatarSrc="/assets/gordi.svg">
  Aquí no se pierde nada. ¿Empezamos suave hoy? 🌱
</GordiBubble>
<GordiBubble from="user">Hoy me cuesta arrancar…</GordiBubble>
```

Always keep copy warm, never pressuring. `from="user"` flips it right + green.
